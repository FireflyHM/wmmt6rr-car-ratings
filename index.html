How the ratings work

  • Acceleration: simulated 100 to 300 km/h time on the normal courses at a 17/17 full tune, from the car's torque curve and gearbox plus value A.
  • Grip: value D (tyre sideways grip). Brakes: value C (brake force).
  • Size: body width plus a quarter of the length. Smaller touches walls and traffic less.
  • Bump: the car's collision weight. Heavier cars get shoved less by the opponent or the ghost. Traffic uses the same weight for every car.
  • Top speed: the peak at the bottom of the Tokyo Port tunnel (value B). It is worth under 2 km/h from best to worst, so it barely counts.
  • Time attack has no traffic or opponents: grip 35%, acceleration 30%, brakes 20%, size 10%, top speed 5%.
  • VS and ghost battles add traffic and bumps: acceleration 30%, grip 20%, size 20%, brakes 15%, bump 10%, top speed 5%.
  • Each part is scaled 0 to 10 across all cars. Grades are by rank: S top 10%, A next 20%, B middle 40%, C next 20%, D bottom 10%.
  • Drive layout (FF, FR, 4WD...) only changes sound and effects, and the old "weight offset" is camera only, so neither is scored. The weights are a judgement call; the parts are read from the game's code, not timed in races.

How top speed works

  • Top speed is set by drag, not the rev limiter. On a flat road a 17/17 full tune balances at about — rpm in top gear, which reads — km/h. The limiter would allow over 400.
  • The 350+ readings come from downhill slopes. On Wangan West the bottom of the Tokyo Port tunnel ramp, — km in, reaches — km/h, and the Haneda-side dip, — km in, — km/h. The New Belt Line uses the same Tokyo Port ramp, so the car table's top speed is the tunnel peak.
  • Every car shares the gearbox top ratio, final drive, wheels and drag. Only value B changes the speed, by about 0.3 km/h a point; an automatic is about 1 km/h slower.
  • The wiki's top speeds follow the same order but read about 1.5 km/h lower, probably because the meter rounds down or players enter the ramp below full speed.
